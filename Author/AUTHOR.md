# Author
Author is a brand new type of authorization and save data system that can be used from across the Internet easily, quickly, and securely. Author mainly specializes in saving game data and simple variables.

## How it works
Author works by saving data underneath *tabs*, which are groups of data associated with a certain website. **Data underneath Tabs are read-only, except when edited from the website of origin.**
*Users* are what the data is associated with. All users have a unique username, and they can have and read data. To minimize cheating, data cannot be edited by users directly. All users have passwords, and users are required to login to access their data in that session.
